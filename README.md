# WardRobe V0.1 — Phone Upload Bootstrap

Questa è la versione piatta del prototipo, pensata per essere caricata su GitHub direttamente da smartphone senza creare cartelle.

## File da caricare nella root del repository

- App.tsx
- package.json
- app.json
- babel.config.js
- tsconfig.json
- README.md

## Cosa include

- Home personale
- Wardrobe a categorie
- Add Item da fotocamera o galleria con crop manuale
- Dressing Room con cambio top / bottom / shoes
- Shuffle e Save Look
- Looks salvati
- Persistenza locale con AsyncStorage

## Nota

Questa è una bootstrap V0.1 intenzionalmente concentrata in un solo file App.tsx.
Quando il repository è online possiamo poi rifattorizzarla in una struttura ordinata (`src/`, `components/`, ecc.) senza cambiare il prodotto.
